- **Desarrollo Full Stack:** Creación de formularios interactivos, validación estricta de esquemas (DTOs / pipes) y diseño de endpoints RESTful.
- **Consultas & Reportes:** Manejo de consultas paginadas, filtros combinados y generación/exportación de reportes a formatos como Excel y CSV.
- **Aseguramiento de Calidad (QA):** Definición de matrices de prueba, pruebas de integración de API con Supertest y automatización de flujos E2E con
Playwright.
- **Mantenimiento Empresarial:** Refactorización modular, control de acceso basado en roles y optimización de servicios existentes.

### 🚀 Proyecto Destacado: [Mesa](https://github.com/JavierHerazoR/mesa-solicitudes)

Sistema de seguimiento y gestión de solicitudes internas con arquitectura modular.

- **Stack:** React 19, NestJS 11, TypeScript, SQLite (`node:sqlite`).
- **QA:** 9 pruebas de API y 4 escenarios de navegación con Playwright aprobados.
- **Funcionalidades:** Ciclo de vida de solicitudes, filtros avanzados combinables, historial de transiciones y exportación CSV completa.
