## Proyecto personal: [Mesa](https://github.com/JavierHerazoR/mesa-solicitudes)

Proyecto de portafolio preparado con asistencia de IA para el seguimiento de solicitudes internas. Usa **React 19, NestJS 11, TypeScript y SQLite** e incluye creación de solicitudes, filtros, historial de estados y exportación CSV.

La versión local cuenta con **8 pruebas de API y 4 escenarios de Playwright aprobados**. Funciona con datos ficticios. El repositorio incluye código, capturas, documentación y pasos de ejecución local.

[Abrir demo](https://mesa-solicitudes.onrender.com) · [Ver código](https://github.com/JavierHerazoR/mesa-solicitudes)

La demo usa datos compartidos y temporales; puede tardar en abrir después de un período de inactividad.
